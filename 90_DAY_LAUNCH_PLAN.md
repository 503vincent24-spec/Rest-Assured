# 90-Day Launch Plan — Rest Assured Moving LLC

A practical, week-by-week roadmap from the first day the project files are
in your hands to a live website, active Google Business Profile, first paid
ads, and your first 25 Google reviews.

This plan prioritizes actions by impact. Do them in order — each layer builds
on the one before it.

---

## Pre-Launch Week (Before anything goes live)

**Goal:** Replace placeholders, test the site, confirm all accounts are ready.

### Days 1–2: Placeholder replacement
- [ ] Open the project folder in VS Code (or any text editor with global search)
- [ ] Global find-and-replace every placeholder from the `README.md` list:
  - `(971) 302-0120` → your business phone
  - `Shawn@restassuredmoving.net` → your business email
  - `[YOUR-DOMAIN]` → your domain (e.g., restassuredmovingllc.com)
  - `95` → your hourly rate
  - `2024` → year business was founded
  - All others listed in README.md
- [ ] Review `index.html` — swap the 3 placeholder testimonials with real reviews
  (if you have any from early customers; if not, remove the testimonial section
  for now and add it once real reviews exist)

### Day 3: Domain and hosting
- [ ] Purchase domain at Namecheap, GoDaddy, or similar ($10–15/year)
- [ ] Create a GitHub account if you don't have one
- [ ] Create a new repository and upload all files from `website/`
- [ ] Enable GitHub Pages (Settings → Pages → main branch → root folder)
- [ ] Configure custom domain DNS per README.md instructions
- [ ] Confirm the site loads at your real domain

### Day 4: Test everything
- [ ] Open the live site on a desktop browser — every page
- [ ] Open on a real phone (not just browser resize) — every page
- [ ] Submit a test quote request → confirm email opens correctly
- [ ] Submit a test contact form → confirm email opens correctly
- [ ] Confirm all navigation links work
- [ ] Confirm the phone number is clickable on mobile
- [ ] Confirm footer year shows current year

### Day 5: Google accounts
- [ ] Set up Google Business Profile (business.google.com)
- [ ] Fill in all profile details using `GBP_CONTENT.md`
- [ ] Request verification (postcard, phone, or video — Google varies this)
- [ ] Set up Google Analytics 4 property → add tracking code to all HTML pages
  per the README instructions
- [ ] Set up Google Search Console → verify domain → submit sitemap.xml

- [ ] Create Facebook Business Page using `FACEBOOK_CONTENT.md`
  — complete the full About section, not just the name
- [ ] Post the pinned introduction post (Post 1 from FACEBOOK_CONTENT.md)
- [ ] Create Instagram account and complete profile using `INSTAGRAM_GUIDE.md`
- [ ] Claim Nextdoor Business Page using `NEXTDOOR_GUIDE.md`

## Month 2 (Days 31–60)

**Goal:** Build review momentum, establish social rhythm, optimize ads.

### Reviews
- [ ] Target: 8–12 Google reviews by end of Month 2
- [ ] If stuck below 5 reviews: tighten the review request timing
  (same-day email, not 48 hours later) and make the verbal request
  more direct at the end of each job
- [ ] Respond to every review within 48 hours using `REVIEW_MANAGEMENT_SYSTEM.md`

### Social media
- [ ] Facebook at 3x/week, Instagram at 3x/week — consistent rhythm established
- [ ] First Instagram Reels: aim for 2 per week (short, phone-filmed)
- [ ] Connect with 3 real estate agents using `REFERRAL_PARTNER_TOOLKIT.md`
  email template

### Advertising
- [ ] Review LSA cost-per-lead after first 30 days — is it under $[TARGET]?
- [ ] If yes: increase LSA weekly budget by 25%
- [ ] If no: check response time (under 2 hours is critical for LSA ranking),
  check whether profile has reviews visible (reviews directly affect LSA
  cost and visibility)

### Website
- [ ] Update the stats on index.html with real numbers (jobs completed, etc.)
- [ ] Add any real crew/job photos taken so far to replace stock imagery
- [ ] Check Google Search Console: which search queries are bringing people
  to the site? Are the right keywords driving traffic?

## Month 3 (Days 61–90)

**Goal:** Optimize what's working, build toward summer season.

### Analytics review (do this at Day 60)
For each lead source, calculate:
- Cost per inquiry
- Inquiry-to-booking rate
- **Cost per booked job** (the number that matters)

Reallocate budget toward the channel with the lowest cost per booked job.

### Reviews
- [ ] Target: 20+ Google reviews by end of Month 3
- [ ] If reviews are strong (20+, 4.8+): raise rates before summer season
  (see `PRICING_GUIDE.md` for timing and method)
- [ ] Begin actively building Nextdoor and Facebook reviews as secondary
  platforms

### Referral partners
- [ ] 5 active partner relationships established (truck rental, real estate,
  apartment managers — see `REFERRAL_PARTNER_TOOLKIT.md`)
- [ ] First referral bookings tracked and partners thanked

### Summer preparation (if in Q1/Q2)
- [ ] Begin "summer dates booking up" messaging on social
- [ ] Increase ad budgets 25–30% for May–August per `SEASONAL_CALENDAR.md`
- [ ] Hire additional crew if you're already booking out 2+ weeks
- [ ] Confirm equipment ready for peak volume

## 90-Day Success Metrics

By the end of Day 90, a healthy launch looks like:

| Metric | Target |
|---|---|
| Google reviews | 20+ at 4.5 stars minimum |
| Monthly website visitors | 150+ (growing) |
| Monthly quote requests | 10+ |
| Booking conversion rate | 35%+ of quotes |
| Active referral partners | 3–5 |
| Social media accounts active | Facebook + Instagram + GBP posts |
| Paid channel running | Google LSA at minimum |

If any metric is significantly below target, the `REVIEW_MANAGEMENT_SYSTEM.md`,
`BOOKING_WORKFLOW.md`, `ADVERTISING_STRATEGY.md`, and `SEASONAL_CALENDAR.md`
each contain diagnostic guidance.

---

## The Single Most Important Thing in the First 90 Days

**Get Google reviews. Every other activity is secondary.**

A business with 20+ genuine 5-star Google reviews in a mid-size market like
Salem will outperform a competitor with a bigger ad budget and a worse
rating. Reviews improve your GBP ranking, your LSA performance, your
website conversion rate, and every customer's first impression.

Make the review request system from `REVIEW_MANAGEMENT_SYSTEM.md` automatic
and consistent before any other marketing activity. It costs nothing and
compounds over time.

Everything else in this project supports that core loop:
**Do excellent work → Request a review → Respond publicly → Repeat.**
